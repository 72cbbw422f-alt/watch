# WATCHLIST

**Your personal film & TV universe.**

WATCHLIST is a cinematic, native iPhone companion for discovering movies and series, keeping a personal watchlist, tracking episodes, seeing upcoming premieres and receiving reminders.

## Product direction
- Cinematic Premium design — immersive artwork, editorial typography, deep graphite surfaces and restrained lime accents.
- Native SwiftUI experience.
- Local-first personal library with SwiftData.
- TMDB as the primary catalogue and metadata source.
- Swedish defaults: `sv-SE` and provider region `SE`.
